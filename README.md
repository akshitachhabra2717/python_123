# Python Utility Scripts

A collection of basic Python scripts for simple mathematical operations and text output.

## Project Structure

- `square.py` – Calculates the square of a number.
- `addition.py` – Adds two numbers together.
- `name.py` – Prints a name.

## Prerequisites

- Python 3.x installed.

## Usage

Run any script directly using Python:

```bash
python square.py
